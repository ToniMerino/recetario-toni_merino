# Actualización a RTM v1.0.0

## Archivos que deben sustituirse

- `index.html`
- `data.js`
- `app.js`
- `styles.css`
- `manifest.webmanifest`
- `sw.js`
- `README.md`

## Archivos nuevos o actualizados de documentación

- `CHANGELOG.md`
- `INVENTARIO_RECETARIO.md`
- `README_ACTUALIZACION.md`

## Instalación con GitHub Desktop

1. Descomprime el ZIP.
2. Copia todos los archivos dentro de la carpeta local `recetario-toni_merino`, aceptando la sustitución.
3. Abre GitHub Desktop.
4. Comprueba los cambios.
5. Escribe el resumen: `Publicar RTM v1.0.0`.
6. Pulsa **Commit to main**.
7. Pulsa **Push origin**.
8. Espera entre 2 y 5 minutos.
9. Abre la web en el navegador y fuerza una recarga.

## Validación

- La cabecera debe mostrar `Versión 1.0.0`.
- El catálogo debe indicar `20 fichas`.
- Deben funcionar los filtros Recetas y Técnicas.
- El buscador debe encontrar, por ejemplo, `Thermomix`, `Iaia Pilar`, `Arroces` y `Navidad`.
